live ERC20 balance — streamed via BalanceTracker (all compute in wasm)

Streams every Transfer log for one ERC20 token touching one wallet. Each chunk is fed straight to BalanceTracker.process(chunk), which walks the Arrow batches in Rust via LogReader::iter/BlockReader::iter, accumulates U256 totals, and returns one delta object per chunk. JS never decodes Arrow itself — the only wasm-bindgen boundary cross is the borrowed ArrowResponse in, the delta JsValue out.
